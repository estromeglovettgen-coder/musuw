## 范围限制与晋级

尚未覆盖用户真实国内运营商及手机的完整登录体验，须在正式发布后验收。
此前一次真实浏览器导航超时，有限复查确认页面可用；首次超时根因未确定。
最终纠正版本的手机尺寸登录页面检查通过，不等于真实短信/邮件验证码链路验证。
客户端诊断是有界、尽力发送；JavaScript 到达前或完全断网时可能无法上报。
持久化范围是应用日志，代理计时沿用现有容器日志轮转。

完整 Paddle Sandbox 生命周期不在本次范围，不得填写 `full-sandbox-e2e-green`。
晋级仍核对完整 SHA、main 祖先、成功 CI、此前 artifact、在线 staging digest、
当前正式环境成功 manifest，以及 `server-production` required reviewer。
保留健康检查和失败回滚，只晋级同一组验收镜像，不在服务器编译或使用可变标签。
