## 范围与行为

临时会话读取错误或超时与真实缺失分开处理，保留授权流程并提供明确重试。
成功操作继续去重，原有回调、客户端、state、nonce、PKCE 校验与存储策略不变。
验证码限流提供准确提示和既有重发冷却，不自动重复发送。

复用现有诊断接口和持久化应用日志，增加有界的匿名关联、固定原因枚举、
导航与启动阶段耗时，以及最多三个同源构建资源的文件名和耗时。
不收集原始 URL、查询参数、验证码、令牌、邮箱、原始 UA 或用户正文。
保持 2048 字节限制、严格字段验证、旧请求兼容与独立限流。
诊断失败不阻塞登录。未引入新身份服务、数据库迁移、付费服务或架构改造。

## 证据限制与晋级

原始夸克事件的完整根因仍未证实。会话读取异常是可复现的错误条件，不证明
当次一定由此触发。真实会话缺失仍需要登录。历史启动等待无法由旧日志追溯
拆分为传输、JavaScript 执行或浏览器调度；新测量用于后续定位，不能证明普遍提速。
启动测量截至应用挂载，并不代表所有内容绘制完成；资源记录仅含已观测到的完成项。
脚本未到达、浏览器计时限制、遥测受阻或关联信息丢失仍可能造成证据缺口。

验收没有发送真实验证码、调用模型或执行在线支付。离线 CI 不等于真实手机完整登录
或完整支付 Sandbox 验收。只晋级同一对已验收镜像，继续校验 main 祖先、精确 SHA
成功 CI、staging artifact、在线 digest、当前正式基线及原有 protected reviewer。
本记录与精确 tuple 更新不改变应用镜像；回滚目标仍为上面的已验证正式基线。
